# Personal Portfolio Website

My personal portfolio website showcasing my engineering background, automation tools, and foundational software projects. Built with a modern, high-performance aesthetic featuring fluid responsiveness, a native dark theme, and an interactive keyboard command palette (`Ctrl + K`).

## 🌐 Live Site
Live architecture deployed cleanly at: [sohanrajadhikari.com.np](https://sohanrajadhikari.com.np)

## 🛠️ Built With
* **Structure:** Semantic HTML5 & Modern CSS3 Grid/Flexbox
* **Interactions:** Vanilla JavaScript (ES6+, Intersection Observer API)
* **Icons & Typography:** Lucide Icons & Google Fonts (Outfit / Inter)
* **DNS & Security:** Cloudflare Universal SSL

## 📁 Core Projects Highlighted
1. **Splexer:** An NLP-based financial tracking and data visualization app built in PHP.
2. **Daraz Tracker:** An automated Python web extraction data pipeline for local e-commerce market metrics.
3. **run_away:** A telemetry running logger built as a CS50 final project focusing on state management.
4. **FundMyVision:** A collaborative Node.js API backend built under time constraints during a hackathon.
